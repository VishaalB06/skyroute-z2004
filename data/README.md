# Data

## Files
| File | Rows | Description |
|---|---|---|
| cities.csv | 27 | All origin/destination cities with IATA codes |
| airlines.csv | 16 | Airlines with IATA codes and hub cities |
| users.csv | 300 | Registered platform users |
| flights.csv | 309 | Scheduled flight routes |
| flight_prices.csv | 5092 | Cabin-class prices per flight per date |
| bookings.csv | 2718 | Core transactional data (2000+ required) |

## Notable additions
- **Etihad Airways** (EY) — hub: Abu Dhabi, operates 14+ routes
- **Abu Dhabi** (AUH) — connected to Africa, Europe, Asia, and India
- **Chennai** (MAA) — connected to Dubai, Abu Dhabi, Doha, London, Frankfurt, Istanbul

## Data Source
Synthetic dataset generated by `generate_data.py` using realistic constraints:
- Real city names and IATA codes
- Real airline names and IATA codes
- Consistent referential integrity across all 6 tables
- Realistic price distributions per cabin class
- Booking statuses weighted: 55% Confirmed, 25% Completed, 15% Cancelled, 5% Pending

## How to Import
```bash
# 1. Run the schema first
psql -d skyroute -f schema/schema.sql

# 2. Import all CSVs
psql -d skyroute -f data/import_data.sql
```
